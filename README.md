# বাজার দর | BazarDor

**প্রয়োজনীয় পণ্যের দাম এক নজরে।** BazarDor is a Bengali-first marketplace price guide that helps shoppers browse categories, compare today’s prices, and find market-level price ranges.

## Features

- Live product and category data from the BazarDor API.
- Home sections for the six biggest price increases and decreases.
- Responsive product cards with Bengali prices, units, and change indicators.
- Category pages with numeric low-to-high and high-to-low price sorting.
- Product detail pages with minimum, maximum, average, and market-specific prices.
- Better Auth email/password and Google sign-in, protected product details, and profile name updates.
- Responsive navigation, date-aware hero, scrolling price ticker, and Bengali UI.

## Technologies

- Next.js App Router (React)
- React
- Tailwind CSS v4
- Better Auth
- MongoDB with the Better Auth Mongo adapter
